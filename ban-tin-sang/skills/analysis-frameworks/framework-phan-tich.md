# 🧠 FRAMEWORK PHÂN TÍCH — Bản tin sáng

> Kỹ năng phân tích có cấu trúc. Dùng khi AI (hoặc bản thân) cần đánh giá thị trường.

---

## FRAMEWORK 1 — Đọc ngày thị trường

```
A. BREADTH (Độ rộng)
   → Bao nhiêu mã tăng / giảm / đứng?
   → Tỷ lệ tăng > 60%? → Tích cực. < 40%? → Thận trọng.

B. LEADERSHIP (Ai dẫn dắt?)
   → Ngành nào tăng mạnh nhất? Có logic không?
   → Ngân hàng dẫn → tốt (weight cao, tiền thật)
   → Penny dẫn → cẩn thận (mang tính đầu cơ)

C. VOLUME (Thanh khoản)
   → So với TB 20 phiên:
     > 120% → Xác nhận mạnh
     80-120% → Bình thường
     < 80% → Thiếu conviction

D. MONEY FLOW (Dòng tiền)
   → Ngoại: mua/bán ròng? Tập trung ngành nào?
   → Tự doanh: vai trò?
   → Proprietary: có bất thường không?

E. CATALYST (Chất xúc tác)
   → Có tin gì hôm qua/hôm nay giải thích biến động?
   → Internal (nội tại VN) hay External (quốc tế)?
```

---

## FRAMEWORK 2 — Đánh giá tin tức

```
Với mỗi tin, trả lời 5 câu:
1. SỰ KIỆN: Chuyện gì xảy ra? (1 câu, có số)
2. BỐI CẢNH: Tại sao lại xảy ra? (macro, chu kỳ, chính sách)
3. TÁC ĐỘNG NGẮN HẠN: Ai hưởng lợi / chịu thiệt hôm nay?
4. TÁC ĐỘNG DÀI HẠN: Xu hướng mới nào đang hình thành?
5. RỦI RO: Điều gì có thể làm nhận định này sai?
```

## FRAMEWORK 3 — Viết Lead Paragraph

```
Công thức: WHAT + NUMBER + WHY (ngắn) + WHAT'S NEXT

Ví dụ tốt:
"VNINDEX tăng 12.4 điểm (+0.98%) lên 1,284.2 hôm qua,
dẫn dắt bởi nhóm ngân hàng sau khi Chính phủ 
công bố gói tín dụng 100,000 tỷ cho doanh nghiệp SME.
Hôm nay thị trường chú ý kết quả KQKD Q2 của VCB."

Tránh:
"Thị trường hôm qua diễn biến tích cực với sự tham gia
của nhiều nhóm ngành..."
```

## FRAMEWORK 4 — Macro → Market Impact

```
Biến số macro → Cách đọc tác động:

CPI tăng → Áp lực lãi suất → Tiêu cực BĐS, ưu tiên ngân hàng
CPI giảm → Dư địa nới lỏng → Tích cực toàn thị trường
FED hike → DXY mạnh → VND áp lực → Áp lực lên import cost
FED cut → Risk-on toàn cầu → EM inflow → Tích cực VNINDEX
Giá dầu tăng → Lợi BSR, PVD / Hại HPG, ngành tiêu thụ nhiên liệu
Tỷ giá mạnh → Lợi xuất khẩu (STK, PHR) / Hại nhập khẩu
```
